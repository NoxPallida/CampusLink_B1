# CampusLink - Mission FR01 (HTML/CSS)

## Contexte
Projet fil rouge B1 CampusLink : Intégration statique et responsive des maquettes sans dépendance JavaScript ou backend.

## Arborescence du Projet
- `index.html` : Page d'accueil du projet
- `css/style.css` : Feuille de style globale (Flexbox, Grid, Responsive)
- `pages/dashboard.html` : Tableau de bord principal
- `pages/salles.html` : Liste des salles du campus
- `pages/equipements.html` : Inventaire des équipements
- `pages/incident.html` : Liste globale des incidents
- `pages/incident-detail.html` : Page de détail d'un incident
- `pages/declaration.html` : Formulaire de déclaration d'un nouvel incident

## Lancement
Ouvrez directement le fichier `index.html` dans un navigateur web.
